安装

Read the whole web in the language you think in.

用你思考的语言，读整个网页。

译览是 Chrome 和 Edge 的翻译扩展。整页双语对照，选中一段就地翻译，框出一块区域看译文，在输入框里写完中文连按三下空格换成英文。代码原样保留，页面不会被弄乱。

添加到 Chrome 下载安装包 Chrome 应用商店即将上架 其他安装方式

Chrome 和 Edge 111 以上免费，不用注册界面支持 8 种语言

功能

每段动图都是装好扩展后的真实操作，点一下可以放大。

整页翻译 划词翻译 一次选几段 框选翻译 滚动扫描 输入框翻译 术语表 解除复制限制 工具栏弹窗

整页翻译

Alt Shift Y

把整个网页翻译成你的语言。默认双语对照，译文以高亮样式排在每段原文下方；也可以直接替换原文，鼠标停在译文上时显示原文。

按 Alt + Shift + Y 开始翻译，再按一次显示原文。按 Alt + Shift + D 在双语对照和替换原文之间切换，不会重新请求。不想记快捷键，就点工具栏上的译览图标，再点「翻译此页面」。

  • 只翻译屏幕附近的内容，往下滚动时接着翻，页面内容更新了也会跟上。
  • 代码块、编辑器、终端和公式不翻译，句子里的行内代码原样保留。
  • 同一个标签页里，接着打开同一网站的其他页面会继续翻译。网站可以在弹窗里设成「总是」或「不翻译」。

划词翻译

选中文字

选中文字后，一个手绘的圈把它圈起来，尖角指向「翻译」按钮。点一下，译文卡片就出现在尖角的位置。翻译中圈是点线，有了结果变成实线。

卡片挡住了原文，就拖着顶部的横条把它移开。卡片上可以复制、朗读译文；选的是单词或短语时，还可以加入术语表。

  • 想更快，可以在设置里把「选中文字后」改成「直接翻译」；不想看到按钮就改成「关闭」，需要时用右键菜单翻译。
  • 在代码块和输入框里选中文字，不会出现按钮。

一次选几段

选中跨段的文字

选中好几个段落时，它们放在同一张卡片里，按段分开。点卡片里的某一段，页面滚到对应的原文并闪一下，方便对照着读。

  • 选区在页面上的同一处时，一个圈把它们一起圈住。
  • 选区散在页面不同位置时（比如跨过侧边栏）不画圈，按钮出现在鼠标旁边。

框选翻译

Shift 空格 S

只想看懂页面上的一块，就拖一个框把它框住。译文直接盖在原文上，页面本身一点不改。表格、卡片、弹窗这些不好选中的地方最适合。

按住 Shift 和 空格，再按 S，然后拖动鼠标框出区域。按 Esc 关闭，或者直接框下一块。弹窗和右键菜单里也有「框选翻译」。

  • 部分中文输入法用 Shift + 空格 切换全角半角，可能同时被触发。可以在设置里换一个组合键。

滚动扫描

Shift 空格 X

框出屏幕上正文所在的一块，然后像平常一样往下滚。经过这个框的内容都会被翻译，收进一张结果卡片，标题、列表和代码块都保留原来的样子。读长文章和长文档时最省事。

按住 Shift 和 空格，再按 X，框出区域后开始滚动。点工具条上的「全屏查看」读结果，按 Esc 结束。

  • 结果可以搜索，可以复制为 Markdown，也可以保存或复制成图片。图片带彩色边框，底部有扩展名水印。
  • 页面固定的导航栏和侧边栏不会被扫进去，来回滚动也不会重复。

输入框翻译

空格 × 3

在网页的输入框里用中文写完，连按三下空格，上方弹出译文预览，按回车就换成译文。回英文邮件、评论和工单时用得上。

先在设置的「输入框翻译」里打开开关，选好要翻译成的语言（默认英语）。按 Enter 替换，按 Esc 取消，替换后按 Ctrl + Z 能撤销。预览左下角可以临时换一种语言，也可以只复制译文。

  • 密码框永远不会被读取。

术语表

卡片上「加入术语表」

机器翻译常把专有名词译歪，比如把消息队列里的 broker 译成“经纪人”。把它加进术语表，以后都按你定的译法翻译；只写原词不写译法，就保持原样不翻。

双击或选中一个词，翻译后点卡片上的「加入术语表」，填好译法保存。整页翻译、划词、框选和输入框翻译都会遵守它。也可以在设置的「规则 → 术语表」里直接写，每行一条：原词 或 原词 = 译法。

  • 写了译法的条目，只在翻译成添加时的目标语言时使用。

解除复制限制

设置里打开

有些网站禁止选中、复制或右键。打开这个设置后，这些限制都会失效：可以正常选中和复制，也能划词翻译。

在设置的「划词翻译」里打开「解除复制限制」，然后刷新受限的页面。默认是关闭的；少数网页开启后可能表现不同，遇到问题关掉就好。

工具栏弹窗

点工具栏图标

点浏览器工具栏上的译览图标，打开弹窗。它有三个部分。

网页翻译
选原文和目标语言，切换双语对照或替换原文，设置这个网站是否自动翻译，开始框选或扫描。
文本翻译
粘贴或输入任意文字直接翻译，最近的翻译会留着。
设置
右上角的按钮。外观、主题色、译文样式、划词、输入框、规则、快捷键和缓存都在这里，改完马上生效。
  • 主题色有 8 种，也能自定义，扩展里所有强调色都跟着变。
  • 设置最下面有「恢复默认设置」。

安装

两种方式任选一种。从应用商店安装会自动更新。

从 Chrome 应用商店安装

  1. 打开译览在 Chrome 应用商店的页面。
  2. 点「添加至 Chrome」，在弹出的确认框里点「添加扩展程序」。
  3. 点工具栏上的拼图图标，把译览固定到工具栏。

用 Edge 也可以从 Chrome 应用商店安装：第一次打开商店页面时，点页面顶部的「允许来自其他应用商店的扩展」，再点「获取」。

前往 Chrome 应用商店即将上架，上架后这里会放上链接

用安装包手动安装

  1. 下载安装包，解压到一个不会被删掉的文件夹。
  2. 在地址栏打开 chrome://extensions，Edge 是 edge://extensions。
  3. 打开「开发者模式」。Chrome 在右上角，Edge 在左侧。
  4. 点「加载已解压的扩展程序」，选择刚才解压的文件夹。
  5. 点工具栏上的拼图图标，把译览固定到工具栏。

手动安装不会自动更新。有新版本时，下载后覆盖原来的文件夹，在扩展页面点译览上的刷新按钮。

规则

术语表
每行一条：原词 保持原样，原词 = 译法 固定译法。
总是翻译的网站
每行一个域名，包含子域名，打开时自动翻译。
停用的网站
不自动翻译，也不显示划词按钮。
总是翻译的语言
语言代码，用逗号分隔，比如 en, ja。
不翻译的元素
CSS 选择器，每行一个。代码块、编辑器和公式已经默认跳过。

快捷键

问题

为什么在起始页和设置页上用不了？

浏览器不允许任何扩展在它自己的页面上运行，包括新标签页、chrome:// 和 edge:// 开头的页面，以及扩展商店。在这些页面上，可以改用弹窗里的文本翻译。

要钱吗？要注册或者密钥吗？

都不用。扩展使用免费的在线翻译服务，装好就能用。

我的文字会被发到哪里？

要翻译的文字会发到在线翻译服务生成译文。服务方没有说明如何保存这些数据，不要用它翻译敏感内容。译览没有自己的服务器，也不收集统计数据。文字只在你操作时发送，例外是你开启的自动翻译和网站规则。输入框只有在你打开输入框翻译、并在里面连按三下空格时才会被读取，密码框永远不会。

会把网页弄坏吗？

不会删除或移动网页上的任何元素，React、Vue 这些框架做的页面照常能更新和点击。显示原文后，页面恢复成翻译前的样子。框选翻译只是在页面上面叠一层，完全不碰页面本身。

哪些内容翻译不了？

图片和 Canvas 里的文字、浏览器自带 PDF 阅读器里的内容。单个词缺少上下文时可能译错，可以用术语表固定。机器翻译会调整语序，链接偶尔会落到相邻的词上，但文字和代码不会丢。

按 Shift + 空格时输入法切成了全角？

部分中文输入法用这个组合切换全角半角。可以在输入法里关掉它，或者在「设置 → 快捷键」里把框选和扫描换成别的组合。
